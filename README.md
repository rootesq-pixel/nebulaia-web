# NebulaIA · web

Web de presentación de NebulaIA (Android + Windows), de System Error.
HTML/CSS/JS estático: shader de nebulosa en WebGL, red neuronal en canvas, GSAP + ScrollTrigger + Lenis.

- Enlaces de descarga y versiones: `js/config.js`
- Capturas de la app: `img/app` (Android) e `img/pc` (Windows)
- Vídeo demo: `media/nebulaia-demo.mp4` (música: «Dreams Become Real», Kevin MacLeod, CC BY 4.0)
